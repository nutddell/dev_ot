# 3D Print Queue (Google Apps Script + Google Sheets)

Web app สำหรับจัดการคิวงานพิมพ์ 3D: ดูงานที่รอพิมพ์ สีที่ใส่ประจำแต่ละเครื่อง (เครื่องละ 4 สี)
และประวัติงานที่พิมพ์เสร็จ ใช้ Google Apps Script (GAS) เป็น backend และ Google Sheets เป็นฐานข้อมูล

ฐานข้อมูล: Google Sheet **"3DPrint JOB"**
(`13fuUSHjSdJ7jBUp0AjRi3HIU7Ze7ZNkMsA5sGZir1dg`) กำหนดไว้ที่ `SPREADSHEET_ID` ใน `code.gs`
— ถ้าจะเปลี่ยนไปใช้ sheet อื่น แก้ค่านี้ค่าเดียว

## โครงสร้างไฟล์

- `appsscript.json` — manifest ของโปรเจกต์
- `code.gs` — server-side logic (เพิ่ม/ลบเครื่อง, บันทึกสี, เพิ่มงาน, ย้ายงานไปพิมพ์เสร็จ)
- `index.html` — หน้าคิวงานพิมพ์ (HTML + CSS + JavaScript ในไฟล์เดียว) เปิดที่ Web app URL
- `order.html` — หน้าคำสั่งงาน เปิดที่ Web app URL + `?page=order`
- `manage.html` — หน้าการจัดการระบบ (`?page=manage`): เพิ่ม/ลบเครื่องพิมพ์, ตั้งสีประจำเครื่องจากสต๊อก
- `stock.html` — หน้าสต๊อก filament (`?page=stock`) เข้าจากหน้าการจัดการระบบ

ทุกหน้ามีปุ่มสลับหน้าใต้หัวเว็บ: 🖨️ คิวงานพิมพ์ / 📝 คำสั่งงาน / ⚙️ การจัดการระบบ
(แต่ละไฟล์ HTML มี CSS/JS ของตัวเองครบในไฟล์ ไม่ใช้ `include()`)

## ฟีเจอร์

สถานะงาน: (คำสั่งงาน 🟨 รอการออกแบบ → 🟩 ส่งเข้าคิวพิมพ์งาน ซึ่งเข้าไปอยู่ในงานค้างพิมพ์ทันที) →
**งานค้างพิมพ์** → (▶ พิมพ์งาน) → **งานกำลังพิมพ์** → (✓ พิมพ์เสร็จแล้ว) → **พิมพ์เสร็จแล้ว**

### แท็บ แดชบอร์ด (สำหรับ monitor)
เรียงจากบนลงล่าง:
1. **🖨️ กำลังพิมพ์** — งานที่พิมพ์อยู่ทุกเครื่อง พร้อมเวลาเริ่ม และ "พิมพ์มาแล้ว X ชม. Y นาที"
   มีปุ่ม **✓ พิมพ์เสร็จแล้ว**
2. **⏳ งานค้างพิมพ์** — งานที่รอ เรียงตามลำดับเข้าคิว พร้อม "รอมาแล้ว ..." มีปุ่ม **▶ พิมพ์งาน**
   (บนจอกว้างข้อ 1 และ 2 จะอยู่ซ้าย/ขวาคู่กัน)
3. **เครื่องพิมพ์** (ดูอย่างเดียว) — การ์ดแต่ละเครื่อง: สถานะ (กำลังพิมพ์ / ว่าง), สี 4 ช่อง
   (ชนิด + รหัสสีจากสต๊อก), งานที่กำลังพิมพ์, จำนวนงานค้าง — เพิ่มเครื่อง/เปลี่ยนสี ไปที่หน้าการจัดการระบบ

### หน้าการจัดการระบบ (`?page=manage`)
- การ์ด **📦 สต๊อก Filament** (สรุปจำนวนรายการ / ม้วน / ที่หมด) → กดเข้าหน้าสต๊อก
- **+ เพิ่มเครื่องพิมพ์** ตั้งชื่ออัตโนมัติตามตัวอักษรวิทยุการบิน (NATO): Alpha, Bravo, Charlie, ...
  Zulu แล้วต่อด้วย Alpha 2, Bravo 2, ... (ชื่อของเครื่องที่ลบไปจะถูกนำกลับมาใช้ก่อน)
- **สีประจำเครื่อง 4 ช่อง ต้องเลือกจากสต๊อก**: คลิกช่องสี → หน้าต่างรายการ filament ในสต๊อก
  (ค้นหาได้, แสดงจำนวนคงเหลือ / หมดสต๊อก) → เลือกแล้วบันทึกทันที / "ล้างช่องนี้"
  - สีที่เคยเลือกเองไว้ก่อนมีหน้าสต๊อกจะขึ้นว่า "ยังไม่ผูกสต๊อก" จนกว่าจะเลือกใหม่จากสต๊อก
- "ลบเครื่อง" ลบได้เฉพาะเครื่องที่ไม่มีงานค้างหรือกำลังพิมพ์

### หน้าสต๊อก Filament (`?page=stock`)
ฟอร์ม:
1. **ชนิดของ filament**: PLA, PLA+, PLA Matte, PLA Silk, PLA-CF, PETG, PETG-CF, ABS, ASA, TPU, PC,
   PA (Nylon), PVA, HIPS, อื่นๆ (แก้รายการได้ที่ `FILAMENT_TYPES` ใน `code.gs`)
2. **รหัสสี** (จากกล่อง) — เก็บเป็นข้อความ เช่น `0012`, `1/2` ไม่ถูกแปลงเป็นตัวเลข/วันที่
3. **สี** — คลิกช่องสีเพื่อเลือกเฉดสี หรือพิมพ์รหัส `#RRGGBB` (รับ `#F00` / ไม่มี `#` ได้)
4. **จำนวน** (ม้วน)

ชนิด + รหัสสีซ้ำกับที่มีอยู่จะไม่ให้เพิ่ม (ให้ปรับจำนวนที่รายการเดิม)
ตาราง: สี, ชนิด, รหัสสี, HEX, จำนวน (ปุ่ม − / +, ป้าย "หมด" เมื่อเป็น 0), ใช้กับเครื่องไหน, แก้ไข / ลบ
กรองตามชนิดได้ — ลบไม่ได้ถ้าสีนั้นใช้อยู่กับเครื่องพิมพ์

### หน้าคำสั่งงาน (`?page=order`)
บันทึกคำสั่งงานก่อนส่งเข้าพิมพ์:
1. **วันที่** (ค่าเริ่มต้น = วันนี้)
2. **ชนิดของงาน**: พวงกุญแจ / Key cap / อื่นๆ
3. **รายละเอียดงาน** (ใช้เป็นชื่องานตอนเข้าคิว เช่น `Key cap: ESC key ลาย Galaxy`)
4. **สีที่อยากได้ 4 ช่อง** — จิ้มสีแบบเดียวกับสีเครื่องพิมพ์
5. **สถานะ**: 🟨 รอการออกแบบ (กรอบเหลือง) / 🟩 ส่งเข้าคิวพิมพ์งาน (กรอบเขียว)

รายการคำสั่งงานแสดงเป็นการ์ดตามสีสถานะ กดเปลี่ยนสถานะ/แก้สีบนการ์ดได้ตลอดจนกว่าจะส่งพิมพ์
กรองได้: กำลังดำเนินการ / รอการออกแบบ / ส่งเข้าคิวพิมพ์งาน / ส่งพิมพ์แล้ว / ทั้งหมด
คำสั่งงานที่ส่งพิมพ์แล้วจะแสดงเครื่องพิมพ์และสถานะงานพิมพ์ (รอพิมพ์ / กำลังพิมพ์ / พิมพ์เสร็จแล้ว)

### แท็บ งานค้างพิมพ์
- คำสั่งงานสถานะ 🟩 **เข้ามาอยู่ในรายการงานค้างพิมพ์เองอัตโนมัติ** (มีไอคอน 📝 + จุดสีที่ต้องการ)
  เรียงตามเวลาที่เปลี่ยนเป็นสีเขียว ปนกับงานที่พิมพ์เพิ่มเอง — ทั้งในแท็บนี้และบนแดชบอร์ด
  - ยังไม่มีเครื่องพิมพ์: เลือกเครื่องจาก dropdown ในแถวนั้น แล้วกด **▶ พิมพ์งาน** → ไปงานกำลังพิมพ์ทันที
  - **↩ กลับไปออกแบบ** → คำสั่งงานกลับเป็น 🟨 และหายจากรายการนี้
- ฟอร์มเพิ่มงาน (ของเดิม สำหรับงานที่ไม่ต้องผ่านการออกแบบ): พิมพ์ชื่องาน + เลือกเครื่องพิมพ์จาก dropdown แล้วกด **เพิ่มเข้าคิว**
  (บันทึกเวลานำเข้าอัตโนมัติ)
- ตารางรวมงานค้างทุกเครื่อง: ชื่องาน, เครื่องพิมพ์ (พร้อมจุดสี), เวลานำเข้า, รอมาแล้ว
- ปุ่ม **▶ พิมพ์งาน** → ย้ายไปงานกำลังพิมพ์ (บันทึกเวลาเริ่มพิมพ์) — ถ้าเครื่องนั้นมีงาน
  กำลังพิมพ์อยู่แล้ว ระบบจะถามยืนยันก่อน
- ปุ่ม **ลบ** → เอาออกจากคิวโดยไม่บันทึกว่าพิมพ์เสร็จ (เพิ่มผิด / ยกเลิกงาน)

### แท็บ งานกำลังพิมพ์
- ตาราง: ชื่องาน, เครื่องพิมพ์, เวลานำเข้า, เริ่มพิมพ์, พิมพ์มาแล้ว
- ปุ่ม **✓ พิมพ์เสร็จแล้ว** → ย้ายไปรายการพิมพ์เสร็จ (บันทึกเวลาเสร็จ)
- ปุ่ม **↩ กลับไปค้าง** → ย้ายกลับไปงานค้างพิมพ์ (กดพิมพ์งานผิด / พิมพ์ไม่สำเร็จต้องพิมพ์ใหม่)

### แท็บ พิมพ์เสร็จแล้ว
ชื่องาน, เครื่องพิมพ์, เวลานำเข้า, เริ่มพิมพ์, เวลาพิมพ์เสร็จ (ล่าสุดอยู่บนสุด)

> หน้าเว็บดึงข้อมูลใหม่ทุก 1 นาที (เห็นงานที่คนอื่นกด และเวลา "พิมพ์มาแล้ว / รอมาแล้ว" อัปเดตเอง)
> บนมือถือ ตารางจะแสดงเป็นการ์ดทีละงาน ปุ่มอยู่ในการ์ด ไม่ต้องเลื่อนซ้ายขวา

## ข้อมูลใน Google Sheet

ระบบสร้าง sheet (พร้อม header) ให้อัตโนมัติเมื่อเปิดใช้งานครั้งแรก:

| Sheet      | คอลัมน์ |
|------------|---------|
| `Printers` | Printer ID, Name, Color 1, Color 2, Color 3, Color 4, Created At |
| `Queue`    | Job ID, Job, Printer ID, Printer Name, Added At, Started At, Order ID |
| `Done`     | Job ID, Job, Printer Name, Added At, Done At, Started At, Order ID |
| `Orders`   | Order ID, Date, Type, Detail, Color 1–4, Status, Created At, Job ID, Printer Name, Ready At |
| `Stock`    | Stock ID, Type, Color Code, Color, Quantity, Created At, Updated At |

- `Queue` เก็บทั้งงานค้างและงานกำลังพิมพ์: **Started At ว่าง = ค้างพิมพ์**, มีเวลา = กำลังพิมพ์
- `Printers.Color 1–4` เก็บ **Stock ID** (ผูกกับชีต `Stock`) — ค่าที่เป็นรหัส hex คือสีแบบเก่าที่ยังไม่ได้ผูกสต๊อก
- สีใน `Stock` / `Orders` เก็บเป็นรหัส hex (เช่น `#ff0000`) ช่องว่าง = ยังไม่ได้ใส่สี
- `Orders.Status`: `design` = รอการออกแบบ, `ready` = ส่งเข้าคิวพิมพ์งาน, `queued` = ส่งพิมพ์แล้ว
  (Ready At = เวลาที่เปลี่ยนเป็นสีเขียว ใช้เรียงลำดับในงานค้างพิมพ์)
- คอลัมน์ Started At / Order ID เพิ่มต่อท้ายของเดิม — sheet ที่มีข้อมูลอยู่แล้วใช้ต่อได้เลย
  (งานเดิมใน Queue จะเป็นงานค้างพิมพ์)

## วิธี Deploy

1. เปิด Google Sheet "3DPrint JOB"
   (https://docs.google.com/spreadsheets/d/13fuUSHjSdJ7jBUp0AjRi3HIU7Ze7ZNkMsA5sGZir1dg/edit)
2. เปิด **Extensions > Apps Script** (หรือสร้างโปรเจกต์แยกที่ script.google.com ก็ได้
   เพราะโค้ดเปิด sheet ด้วย ID อยู่แล้ว)
3. มี 5 ไฟล์: เปลี่ยนชื่อไฟล์ `Code.gs` เริ่มต้นเป็น `code.gs` และกด **+ > HTML**
   สร้างไฟล์ชื่อ `index`, `order`, `manage`, `stock` (editor จะแสดงเป็น `.html` ให้เอง)
4. คัดลอกเนื้อหาจาก `code.gs`, `index.html`, `order.html`, `manage.html`, `stock.html`
   ในโฟลเดอร์นี้ไปวางแทนของเดิมทั้งหมด
5. เปิด **Project Settings** > ติ๊ก "Show appsscript.json manifest file" แล้วแก้ให้ตรงกับ
   `appsscript.json` ในโฟลเดอร์นี้ (ไม่บังคับ — เวลาบนหน้าเว็บกำหนดเป็นเวลาไทยไว้ที่ `TIME_ZONE` ใน `code.gs` แล้ว)
6. กด **Deploy > New deployment**
   - Select type: **Web app**
   - Execute as: **Me** (ทุกคนเขียนลง sheet เดียวกันได้โดยไม่ต้องแชร์สิทธิ์ sheet)
   - Who has access: เลือกตามต้องการ (เช่น Anyone with Google account หรือเฉพาะในองค์กร)
7. ครั้งแรกจะมีหน้าขอสิทธิ์ (Authorize access) ให้กดอนุญาตการเข้าถึง Google Sheets
   (ถ้าขึ้น "Google hasn't verified this app" ให้กด Advanced > Go to ... (unsafe) ได้ เพราะเป็น
   script ของเราเอง)
8. กด Deploy แล้วคัดลอก Web app URL ไปใช้งาน (bookmark ไว้ในเครื่อง / มือถือได้เลย)

> แก้โค้ดภายหลัง: กด **Deploy > Manage deployments > Edit > Version: New version**
> เพื่อให้ URL เดิมใช้โค้ดใหม่

### ใช้ clasp (ทางเลือกสำหรับ deploy ผ่าน CLI)

```bash
npm install -g @google/clasp
clasp login
clasp create --type webapp --title "3D Print Queue"
# คัดลอกไฟล์ในโฟลเดอร์นี้ไปยังโฟลเดอร์โปรเจกต์ที่ clasp สร้าง แล้ว
clasp push
clasp deploy
```
